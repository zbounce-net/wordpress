# ZBounce Email Validator 1.2.5

Email verification for WordPress registration, Contact Form 7, WooCommerce classic checkout and Checkout Block, Gravity Forms, WPForms and Ninja Forms.

## English

- Choose which verification results allow or reject submissions, including risky/catch-all addresses and service outages.
- Check addresses manually, inspect remaining credits and optionally bypass the local cache from settings. Automatic form verification is independently opt-in.
- API keys remain server-side; administrative actions require permissions and nonce validation. Local cache supports WordPress personal-data export and erasure.
- English interface plus Russian, German, French, Ukrainian and Simplified Chinese translations.
- Release 1.2.5 removes developer logging, fixes translation registration and resolves all four earlier Plugin Check warnings.

**Install only `zbounce-email-validator-1.2.5.zip`.** The `-release.zip` contains RU/EN manuals, upgrade/rollback and privacy/security documentation, GPL license, source archive and checksums. The `-source.zip` is for developers, not WordPress installation. SHA-256 files accompany all three archives.

Requires WordPress 5.0+ and PHP 7.4+. The plugin is GPLv2-or-later; remote verification requires purchased ZBounce credits, an API key and explicit acceptance of the service agreement. No key or credits are included.

Validated: 105 PHP assertions, Chrome settings scenarios, five bundled locale loading checks and PHP 7.4 syntax. Plugin Check 2.1.0: zero errors/warnings. WordPress.org automated submission scan: Pass; manual review is pending. The legacy WordPress runtime matrix and licensed Gravity Forms browser installation were not fully tested.

## Русский

- Настраиваемые правила разрешения и отклонения адресов, включая risky/catch-all и недоступность сервиса.
- Ручной тестер, баланс кредитов и обход локального кэша в настройках. Автоматические проверки форм включаются отдельно.
- Ключ остаётся на сервере; административные действия защищены проверкой прав и nonce. Локальный кэш поддерживает экспорт и удаление персональных данных WordPress.
- Английский интерфейс и переводы на русский, немецкий, французский, украинский и упрощённый китайский.
- В 1.2.5 удалён отладочный журнал, исправлена регистрация переводов и устранены все четыре прежних предупреждения Plugin Check.

**Устанавливайте только `zbounce-email-validator-1.2.5.zip`.** В `-release.zip` находятся инструкции RU/EN, обновление и откат, документация по данным и безопасности, GPL, исходники и контрольные суммы. `-source.zip` предназначен для разработчиков. Для всех трёх архивов приложены SHA-256.

Требуются WordPress 5.0+ и PHP 7.4+. Плагин распространяется по GPLv2 или более поздней версии. Удалённая проверка требует приобретённых кредитов ZBounce, ключа и принятия соглашения сервиса. Ключ и кредиты в комплект не входят.

Пройдены 105 PHP-проверок, браузерные сценарии настроек, загрузка пяти переводов и синтаксис PHP 7.4. Plugin Check 2.1.0: ошибок и предупреждений нет. Автоматическая проверка заявки WordPress.org пройдена; ручное ревью ожидается. Полная матрица старых WordPress и браузерная установка лицензированного Gravity Forms не проверялись.
