# WordPress.org submission

Upload only `zbounce-email-validator-1.2.5.zip` at https://wordpress.org/plugins/developers/add/ after signing in to the intended maintainer account. The documentation bundle is not the submission ZIP. Submission has not been performed by these build tools.

The directory performs manual review. Review the plugin name before submission: the name determines the proposed slug, and an approved slug cannot be renamed. The package uses the name ZBounce Email Validator and directory/text domain `zbounce-email-validator`; the final allocated slug is determined by WordPress.org.

The readme discloses paid external verification, consent, payload, local storage and service policies. PHP/CSS/JS sources and GPL license are included without obfuscation. No WordPress core, tests, mocks, credentials or unrelated plugins are installed by the ZIP. Five bundled translations support direct ZIP installation.

Before submission, validate `readme.txt` with the WordPress.org readme validator and run Plugin Check on the final installer in a separate test site. The 1.2.5 installer passed Plugin Check without errors or warnings; review any new findings reported for your environment. Approval remains the Plugins Team's decision. Once approved, publish through the assigned SVN repository, maintaining matching version/stable tag and a complete tagged release; uploading this local archive does not create an SVN release.

References: [submission page](https://wordpress.org/plugins/developers/add/), [guidelines](https://developer.wordpress.org/plugins/wordpress-org/detailed-plugin-guidelines/), [readme format](https://developer.wordpress.org/plugins/wordpress-org/how-your-readme-txt-works/).
