# ZBounce Email Validator 1.2.5

## Установка и настройка
Требуются WordPress 5.0+ и PHP 7.4+. Установите `zbounce-email-validator-1.2.5.zip` через Плагины → Добавить → Загрузить плагин и активируйте его. Полный релизный архив с документацией не предназначен для установки в WordPress.

Откройте Настройки → ZBounce Email. Купите кредиты на https://zbounce.net/pricing.html, сохраните API-ключ и примите соглашение сервиса https://zbounce.net/license.html. Код плагина распространяется по GPLv2 или более поздней версии; условия внешнего сервиса действуют отдельно. Ключ и кредиты в комплект не входят.

Баланс и ручной тестер администратора доступны независимо от автоматической проверки форм. Включайте автоматическую проверку, когда готовы проверять обращения посетителей. Само сохранение ключа не подтверждает его действительность или наличие кредитов: используйте проверку подключения и баланса. Недоступный баланс не означает нулевой баланс.

## Проверки, кредиты и кэш
Введите адрес в тестер настроек. Включённая галочка кэша позволяет использовать сохранённый результат без новой удалённой проверки. Выключите её для свежей проверки, которая может расходовать кредиты. Запрос баланса не проверяет адрес. Баланс может сохраняться на срок до 60 секунд.

Результаты адресов кэшируются на 1–168 часов, по умолчанию 24 часа. Неопределённые результаты и ошибки API не кэшируются. Изменённые правила сразу применяются к сохранённым фактам. Проверка не гарантирует доставку и не исключает все злоупотребления.

## Разрешённые результаты
| Результат | По умолчанию | Значение |
| --- | --- | --- |
| valid | Разрешить | Положительный результат |
| risky | Разрешить | Неопределённость catch-all / accept-all |
| unknown | Разрешить | Неопределённый результат почтового ящика |
| unavailable | Разрешить | Ошибка обращения к сервису |
| invalid | Отклонить | Некорректный адрес |
| disposable | Отклонить | Одноразовый адрес |
| no_mx | Отклонить | Домен не принимает почту |
| mailbox_not_found | Отклонить | Ящик не найден |

Выберите собственные правила галочками в настройках. Встроенная проверка формата самой формой сохраняется. При выключенной автоматической проверке плагин не проверяет формы и не блокирует их по сохранённым результатам.

## Интеграции и языки
Поддерживаются Contact Form 7, регистрация WordPress, обычный checkout и Checkout Block WooCommerce, выбранные формы Gravity Forms, WPForms и Ninja Forms. В Checkout Block проверка выполняется при POST оформления заказа до оплаты; промежуточные GET/PUT/PATCH не расходуют кредиты. Проверьте именно те формы, которые использует ваш сайт. Шорткод `[zb_email_validator]` доступен только администраторам и не предназначен для публичного расходования кредитов.

Исходный язык — английский. В комплекте русский, немецкий, французский, украинский и упрощённый китайский. Язык выбирается настройками сайта/профиля WordPress. Каждый каталог содержит все 105 текущих сообщений интерфейса.

## Диагностика и поддержка
Неактивные кнопки: сохраните непустой ключ и примите соглашение. Ошибка подключения: проверьте ключ, кредиты, доступ сервера по HTTPS и доступность сервиса. Неожиданный результат формы: проверьте правила статусов и собственную проверку формы. Повторное отключение кэша с настоящим ключом может расходовать кредиты.

Поддержка: support@zbounce.net. Укажите версии плагина, WordPress, PHP, интеграцию и шаги воспроизведения. Не отправляйте ключи, пароли и списки клиентов. Инструкция для тестового окружения — `tests/stand/README.md` в архиве исходников.
