# Подача в WordPress.org

После входа под учётной записью будущего сопровождающего загрузите только `zbounce-email-validator-1.2.5.zip` на https://wordpress.org/plugins/developers/add/. Архив документации не предназначен для подачи. Инструменты сборки не отправляют заявку автоматически.

Плагин проходит ручное рассмотрение. Перед подачей проверьте имя: оно определяет предлагаемый slug, а одобренный slug переименовать нельзя. В комплекте используется имя ZBounce Email Validator и каталог/text domain `zbounce-email-validator`; окончательный slug назначает WordPress.org.

Readme описывает платную внешнюю проверку, согласие, отправляемые данные, локальное хранение и документы сервиса. Исходники PHP/CSS/JS и GPL включены без обфускации. ZIP не содержит WordPress, тесты, подмену API, ключи и сторонние плагины. Пять встроенных переводов поддерживают установку из ZIP.

Перед подачей проверьте `readme.txt` валидатором WordPress.org и запустите Plugin Check для итогового ZIP на отдельном тестовом сайте. Установочный архив 1.2.5 прошёл Plugin Check без ошибок и предупреждений; рассмотрите новые замечания, если они появятся в вашем окружении. Одобрение остаётся решением команды каталога. После одобрения публикация выполняется через выделенный SVN-репозиторий с совпадающими версией/stable tag и полной версией в tags; локальная сборка не публикует SVN-релиз.

Источники: [страница подачи](https://wordpress.org/plugins/developers/add/), [правила](https://developer.wordpress.org/plugins/wordpress-org/detailed-plugin-guidelines/), [формат readme](https://developer.wordpress.org/plugins/wordpress-org/how-your-readme-txt-works/).
